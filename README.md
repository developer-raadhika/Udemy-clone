# 🎓 Udemy Clone

A simple **Udemy Clone** built using **HTML5**, **CSS3**, and **basic CSS animations**. This project recreates the look and feel of the Udemy homepage while helping beginners practice front-end web development fundamentals.

## 🚀 Features

* Responsive homepage layout
* Navigation bar
* Search bar
* Course cards and categories
* Basic CSS hover and transition animations
* Clean and beginner-friendly code

## 🛠️ Technologies Used

* HTML5
* CSS3
* Basic CSS Animations

## 🌐 Live Demo

👉 **https://developer-raadhika.github.io/Udemy-clone/**

## 📌 About

This project was created for learning and practicing front-end web development using only HTML and CSS. It focuses on building responsive layouts, improving styling skills, and adding simple animations without using JavaScript or any frameworks.
